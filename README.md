## 📌 Technical Overview

**My First App** serves as a foundational implementation of Apple's modern **SwiftUI** declarative paradigm. It illustrates decoupled view components (`ContentView.swift`, `ByeView.swift`), dynamic image scaling, and native system color accents.

---

## 🏛️ Engineering Highlights

- **Declarative View Composition**: Modular component hierarchy separating primary layout from subviews.
- **SF Symbols Integration**: Vector typography scaling dynamically with system accessibility settings.
- **Xcode Previews (`#Preview`)**: Rapid interactive canvas feedback for instantaneous UI iteration.

## 🚀 How to Build and Run

### Prerequisites
- **Xcode 15.0+**
- **iOS 17.0+** Simulator or Physical iOS Device

### Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/snaimio/my-first-app-swift.git
   cd my-first-app-swift
   ```

2. **Open in Xcode:**
   ```bash
   open MyFirst.xcodeproj
   ```

3. **Run Application:**
   - Select an iOS Simulator and press **⌘ + R**.
